# 局域网访问

本机现有无线网络地址：`172.20.10.5`；有线地址：`192.168.1.2`。

另一台设备与本机连接同一个 Wi-Fi/手机热点后访问：

- 登录页：`http://172.20.10.5:8081/login.html`
- Python API：`http://172.20.10.5:8000/docs`
- Java 健康检查：`http://172.20.10.5:8080/api/glasses/health`
- 眼镜 WebSocket：`ws://172.20.10.5:8080/ws`，握手头必须包含 `X-Device-Id`。

同一有线网络内可以将上述 IP 替换为 `192.168.1.2`。前端会自动根据访问页面的主机名选择 Java 的 8080 和 Python 的 8000 端口。

管理员账号 `admin`，初始化密码 `123123`。初始化数据来自项目 `ai.sql`，导入到原本不存在的 `aiinterviewerdb`，未覆盖现有业务库。

本机 MySQL 使用 `root` / 空密码；Java 本次启动通过参数覆盖旧密码，Python `.env` 已同步。Redis 和 MySQL 不需要让另一台设备直接连接。

当前 Windows 防火墙各配置文件处于关闭状态，本次没有修改防火墙。如之后开启，只需对同一局域网放行 TCP 8081、8080、8000 和文件访问所需的 9000。不要关闭整个防火墙。

局域网另一台设备的实际连接仍需由该设备打开链接确认。IP 变化后应重新确认地址并同步 Java 允许的前端来源。

浏览器中的麦克风/摄像头功能通常要求 HTTPS 或 localhost；普通局域网 HTTP 可用于管理页面和接口联调，音视频采集需要额外配置 HTTPS。眼镜原生手机端不受浏览器安全上下文限制。
