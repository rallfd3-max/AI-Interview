简介

CXR-M SDK 是面向移动端的开发工具包，主要用于构建手机端与 Rokid Glasses 的控制和协同应用。与Rokid AI APP 的作用一致，无法同时与Rokid AI APP 在同一个设备上使用。

开发者可以通过 CXR-M SDK 与眼镜建立稳定连接，实现数据通信、实时音视频获取以及场景自定义。它适合需要在手机端进行界面交互、远程控制或与眼镜端配合完成复杂功能的应用。目前 CXR-M SDK 仅提供 Android 版本。

同时开发者可以通过在眼镜端开发应用，并接入CXR-S SDK，从而与移动端的-M 之间展开通信，构建更自由的眼镜端和手机端的协同，完成更复杂的应用。

CXR SDK 与Glasses 架构

Rokid Glasses 设备连接与管理

开发者可以使用CXR-M SDK 与Rokid Glasses 进行连接，并可以在连接成功之后进行回连。

  • 初始化连接
  • 回连

Rokid Glasses 音频控制

开发者可以使用CXR-M SDK 获取Rokid Glasses 上的音频，同时可以控制Rokid Glasses 的拾音模式。

  • Rokid Glasses 音频监听
  • 控制Rokid Glasses 试音模式

Rokid Glasses 照片控制

开发者可以通过CXR-M SDK 控制Rokid Glasses 拍照，并可以直接获取拍照结果。

  • 设置拍照参数并拍照
  • 拍照并获取照片结果

Rokid Glasses 录像控制

开发者可以通过CXR-M SDK 控制Rokid Glasses 进行录像，并可以直接获取录像结果。

  • 设置录像参数并控制Rokid Glasses 录像
  • 获取视频流

Rokid Glasses 媒体文件同步

开发者可以通过CXR-M SDK 获取Rokid Glasses 上的媒体文件数量，并将媒体文件同步到移动端。

  • 获取Rokid Glasses 上的未同步文件数量
  • 同步媒体文件
  • 连接Rokid Glasses 上的Wi-Fi P2P Group

Rokid Glasses 自定义界面

开发者可以通过CXR-M SDK 制作并将自定义界面展示到Rokid Glasses 上。

  • 支持RelativeLayout、LinearLayout
  • 支持ImageView、TextView
  • 支持Lottie 动画
  • 支持更新界面

Rokid Glasses 上的TTS 与通知/Toast

开发者可以通过CXR-M SDK 在Rokid Glasses 上使用TTS；也可以将通知和Toast 展示到Rokid Glasses 上。

  • 支持发送TTS 内容到Rokid Glasse 上，并使用TTS 播报
  • 支持将Toast 内容展示到Rokid Glasses 上
  • 支持将通知内容展示到Rokid Glasses 上

Rokid Glasses 自定义指令功能

开发者可以通过CXR-M SDK 与基于CXR-S SDK 构建的眼镜端应用进行高效的自定义指令交互，构建属于自己的眼镜端和移动端应用场景。

  • 发送自定义指令
  • 接收来自眼镜端应用的自定义指令

Rokid Glasses 自定义场景交互

开发者可以通过CXR-M SDK 快速接入YodaOS-Sprite 操作系统定义的场景交互流程。快速根据YodaOS-Sprite 定义的交互场景进行自定义动能开发。

  • 自定义AI 助手
  • 自定义翻译功能
  • 自定义提词器功能
  • 自定义显示
