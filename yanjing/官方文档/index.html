Rokid Glasses 裸机开发简介

定位

本开发者文档说明如何在 Rokid Glasses 本机（系统 YodaOS-Sprite，基于 Android 12（API 31） / Android Go）上编写、调试普通 Android 应用，使用标准 Android API，不依赖 手机端协同 SDK。

典型场景：Launcher、系统工具、本机录音/拍照/录像、按键与佩戴状态监听、IMU 演示等。

运行环境

项 说明
眼镜系统 YodaOS-Sprite，Android 12（API 31） / Android Go
应用 minSdk 31（与 GlassesBareDevSample 一致）
Sample targetSdk 36（与示例工程一致）
推荐 IDE Android Studio
联调 专用开发线 + 手机 Rokid AI App 开启眼镜 ADB（见 快速开始）

系统与约束

  • 须遵守 Android Go 开发约束。
  • 屏幕：480 × 640 px；UI 规范见 眼镜 UI 设计规范 专章。
  • 产品视觉：Rokid 眼镜设计规范。

设备能力概览

能力 接入方式 专章
480×640 单绿显示 Compose / 标准 View 眼镜 UI 设计规范
镜腿功能键 + 右触控板（TouchPad） 系统广播 + KeyEvent 按键与佩戴和折叠
8 通道原始音频 AudioRecord 眼镜原始音频
拍照 / 录像 CameraX 拍照 / 录像
